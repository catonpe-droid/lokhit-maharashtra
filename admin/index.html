📰 लोकहित महाराष्ट्र — News Admin

आता बातम्या, १० Editor नावे आणि Login व्यवस्था Google Sheet वर ठेवली आहे. मुख्य वेबसाइट GitHub वरच राहील.

📗 Google News Sheet उघडा

फक्त पहिल्यांदा Admin App सुरू करण्यासाठी:
  1. Google Sheet उघडा → Extensions → Apps Script
  2. तयार Apps Script Code पूर्ण कॉपी करून Code.gs मध्ये Paste व Save करा
  3. Sheet पुन्हा उघडा → लोकहित Admin → PIN सेट / बदल करा
  4. Apps Script → Deploy → New deployment → Web app → Execute as Me → Anyone → Deploy

PIN ब्राउझरमध्ये साठवत नाही. Login करताना “या ब्राउझरवर ३० दिवस Login लक्षात ठेवा” पर्याय आहे. **Web App लिंक तयार झाल्यावर** ती जोडून नियमित Admin सुरू करायचा आहे.
